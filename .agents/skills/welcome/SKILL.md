# Welcome the user (inspiration: Tomorrowkit)

This Mind was created from the **Tomorrowkit** inspiration. Its manifest is
`inspiration-tomorrowkit.md` at the repository root.

On the first turn, do all of the following:

1. Read the entire manifest and
   `.agents/skills/tomorrowkit-provisional/SKILL.md` before responding.
2. Welcome the user to Tomorrowkit by name. Explain in one or two sentences
   that this Mind will become a private workspace for one invention, combining
   a guided agent conversation with a visual, portable matter record.
3. Say that no connector or additional API key is required to begin. The
   workflow uses the agent already configured for this Mind.
4. Ask one question and end there: “What is the core idea you want to work on,
   in your own words?”

Do not present a generic Minds suggestions list, ask the user to copy a prompt,
or dump the whole patent process into the first response. Follow the manifest's
adaptation sequence after they answer.
